# Sharp N Shine – אתר העסק

אתר רב-עמודי בעברית (RTL), סטטי וללא תלויות: מחולל Node קצר שמייצר HTML נקי ל-`dist/`. Mobile-first, ללא סקריפטים של צד שלישי וללא מעקב.

## הרצה מקומית
```bash
cd sharp-n-shine
npm start        # בונה ומגיש ב-http://localhost:4173
npm run build    # בנייה בלבד ל-dist/
npm test         # בנייה + בדיקות סטטיות + בדיקות דפדפן (Playwright, גלישה אופקית, תפריט, גלריה, טופס)
```
נדרש Node 20+. לבדיקות דפדפן נדרש Playwright (מותקן גלובלית, או `npm i -D playwright`).

פרסום (לא בוצע): `SITE_URL=https://הדומיין npm run build` ואז העלאת `dist/` לכל אחסון סטטי. עם `SITE_URL` נוצרים גם `canonical`, `og:url` ו-`sitemap.xml`. האתר מניח הגשה משורש הדומיין.

## מבנה
- `content/site.mjs`: **מקור יחיד** לטלפון, שעות, כתובת, קישורים, שירותים, המלצות, שאלות נפוצות ופרויקטים. כאן מעדכנים.
- `scripts/build.mjs`: תבניות העמודים והרכיבים (ניווט, כותרת, תחתית, כרטיסים).
- `src/styles.css`, `src/main.js`: עיצוב ואינטראקציות (תפריט נייד, סינון גלריה, מציג תמונות, טופס).
- `assets/`: קבצים סטטיים (favicon, תמונת שיתוף `og-image.png`, `gallery/`).

## הוספת תמונות אמיתיות לגלריה
שמרו את הקבצים ב-`assets/gallery/` בשם `<slug>-before.jpg` ו-`<slug>-after.jpg` (גם png/webp), כשה-slug מתוך `projects` ב-`content/site.mjs` (`golf`, `audi-q5`, `tesla-model-3`, `audi-sq5`, `peugeot-208`, `smart`). רצוי יחס 4:3 ורוחב כ-1200px. הבנייה מזהה אותם ומחליפה את המקום השמור. השתמשו רק בתמונות שהעסק הסכים לפרסם.

## הטופס
אין שרת. אחרי ולידציה נפתח וואטסאפ (או טיוטת אימייל) עם הודעה מוכנה, והממשק מציין שההודעה נשלחת רק לאחר אישור באפליקציה. לחיבור שירות טפסים בעתיד יש לערוך את `submitVia` ב-`src/main.js` ולעדכן את מדיניות הפרטיות.

## תוכן שדורש אישור בעל העסק
- תמונות לפני/אחרי אמיתיות וזכויות פרסום.
- דומיין ייצור (`SITE_URL`).
- אישור על מוצרי הציפוי, תקופת אחריות/עמידות ותקופות עבודה, אם רוצים לפרסם אותם.
- שעות לשבת, ושיתוף פעולה עם ספקים (Koch Chemie לא מוזכר כשותפות).
- בדיקה משפטית של מדיניות הפרטיות והצהרת הנגישות (כרגע טיוטות מסומנות).
